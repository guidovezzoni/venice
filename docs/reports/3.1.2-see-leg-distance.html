Story

3.1.2 — See Distance for Each Leg: As a user, I want to see the distance for each leg of the trip so that I can understand how far each segment is.

Branch

feature/3.1.2-see-leg-distance created from main

Refinement Summary

Analysis of the codebase reveals that story 3.1.1 (Calculate Route Between Stops) already implemented the full data pipeline and UI display for leg distance:

  • The Leg domain model already contains distanceMetres: Int
  • The LegEntity database entity persists distance in the legs table
  • The LegSummary composable already formats and displays distance (metres for <1 km, kilometres with one decimal for ≥1 km)
  • String resources for both formats already exist
  • LegSummary is already rendered between stops on the trip detail screen

Key Refinement Decisions

  • SCOPED OUT Imperial locale support (miles) — current implementation is metric only; can be a separate enhancement
  • CLARIFIED When no route is calculated, legs simply do not appear (no "—" placeholder needed, as the original story suggested)
  • NOTED Implementation is largely complete from story 3.1.1; remaining work is primarily verification and any missing test coverage

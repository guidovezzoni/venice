Change Proposed

15 Jun 2026

Source: opsx:propose

Exploration Findings

Investigated the codebase to identify integration points for route calculation:

  • API key: Already configured via BuildConfig.MAPS_API_KEY from local.properties
  • No HTTP client: Project uses Google Places SDK (not HTTP-based). OkHttp needed for Directions API REST calls
  • Database: Currently at version 2 (TripEntity, StopEntity). Requires MIGRATION_2_3 for legs table
  • Stop mutations: All go through use cases (SetStopUseCase, MoveStopUseCase, EditStopUseCase, RemoveStopUseCase). Two already have TODO comments for leg invalidation (Epic 3)
  • withMinimumDuration: Already exists for 500ms minimum loading pattern — reusable
  • MVI pattern: Clean UiState/UiIntent/UiEffect contract in place

Design Decisions

DecisionChoiceRationale
HTTP clientOkHttp + org.jsonIndustry standard; org.json built into Android — no extra dependency for single response type
Invalidation strategyDomain-level (use case injection)Enforces invariant regardless of caller; existing TODOs anticipate this pattern
Leg displayInline distance/duration between stopsProvides immediate value without map rendering

# 8.1.5 — Log Out

**Epic:** Cloud Sync & Multi-User
**Feature:** Backend Foundation & Auth

## User Story

As a user, I want to log out of my account so that my data is not accessible to others on this device.

## Description

A log-out action is available from the app (e.g. settings or profile menu). Logging out clears the session and navigates the user back to the login screen. Local cached data (if any) should be cleared on logout to prevent stale data from appearing on a different account.

## Acceptance Criteria

- A log-out option is accessible from the UI (e.g. a menu item or button).
- Tapping log out clears the Supabase session.
- The user is navigated to the login screen after logging out.
- Local cached data is cleared on logout (if offline+online mode is used).
- The user cannot access authenticated screens after logging out.

## Technical Notes

- **Supabase Auth:** Use `supabase.gotrue.signOut()`.
- **Local data:** If Room is kept as a cache, all local tables should be cleared on logout to avoid data leaking between accounts.

# 3.1.2 — See Distance for Each Leg

**Epic:** Route Calculation
**Feature:** Leg Calculation

## User Story

As a user, I want to see the distance for each leg of the trip so that I can understand how far each segment is.

## Description

After route calculation, each leg displayed on the trip detail screen shows the distance between its two consecutive stops in a human-readable format. The distance is shown in metric units (metres for short distances, kilometres with one decimal for longer ones). When no route has been calculated yet, no leg information is shown at all (legs simply do not appear between stops).

## Current State Analysis

Story 3.1.1 (Calculate Route Between Stops) already implemented the end-to-end data pipeline and display for leg distance:

- **Domain model**: `Leg.distanceMetres: Int` stores distance in metres
- **Database**: `LegEntity.distanceMetres: Int` persists leg distance in the `legs` table
- **API**: Google Routes API response is mapped through `LegMapper` to populate `distanceMetres`
- **UI**: `LegSummary` composable already formats and displays distance using `formatDistance()`:
  - Distances under 1 km are shown as `{n} m` (e.g. "750 m")
  - Distances of 1 km or more are shown as `{n.n} km` (e.g. "12.5 km")
- **String resources**: `trip_detail_leg_distance_metres` and `trip_detail_leg_distance_kilometres` already exist
- **Display position**: `LegSummary` is rendered between consecutive stops on the trip detail screen, showing distance alongside duration in the format `12.5 km · 15 min`

## Acceptance Criteria

1. Each leg in the trip detail view shows its distance between the two stops it connects.
2. Distance is displayed as:
   - `{n} m` for distances under 1,000 metres (e.g. "750 m")
   - `{n.n} km` for distances of 1,000 metres or more (e.g. "12.5 km")
3. If no route has been calculated, no leg distance information appears (legs are absent from the UI).
4. Leg distance is visible for all legs: starting point to first intermediate stop, between intermediate stops, and last intermediate stop to destination.

## Locale Considerations

The original story mentioned locale-based unit selection (metric vs imperial). The current implementation uses metric units only (metres and kilometres). Imperial locale support (miles) is **out of scope** for this story — it can be addressed as a separate enhancement if needed.

## Original User Story

### User Story

As a user, I want to see the distance for each leg of the trip so that I can understand how far each segment is.

### Description

After route calculation, each leg displays the distance between its two stops. Distance is shown in a human-readable format (km or miles, depending on locale).

### Acceptance Criteria

- Each leg in the trip view shows its distance.
- Distance is displayed in kilometres (with one decimal place) for metric locales or miles for imperial locales.
- If the route has not been calculated yet, distance is shown as unavailable (e.g., "—").

### Technical Notes

- The Google Directions API returns distance in metres (`legs[].distance.value`). Store as integer metres in the database; format for display in the UI layer.
- Locale-based unit selection can use `Locale.getDefault()` to determine metric vs imperial.

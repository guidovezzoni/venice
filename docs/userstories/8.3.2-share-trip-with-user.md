# 8.3.2 — Share Trip with Another User

**Epic:** Cloud Sync & Multi-User
**Feature:** Trip Sharing

## User Story

As a user, I want to share a trip with another person so that we can plan the roadtrip together.

## Description

The trip owner can invite another user by email. An entry is created in the sharing table, and the invited user sees the trip in their trip list. The sharing model and permission levels are defined in story 8.3.1.

## Acceptance Criteria

- The trip owner can initiate sharing from the trip detail screen.
- The owner enters an email address to invite another user.
- The invited user sees the shared trip in their trip list.
- The sharing permission level (e.g. editor) is assigned at invite time.
- The owner can remove a shared user's access.
- If the invited email is not yet registered, the share is pending and resolves when they sign up.

## Technical Notes

- **Blocked by:** Story 8.3.1 (sharing model design).
- **RLS:** The share action inserts into `trip_members`; RLS must allow the trip owner to insert members for their own trips.
- **Pending invites:** For non-registered emails, store the invite by email and resolve via a database trigger on user registration.

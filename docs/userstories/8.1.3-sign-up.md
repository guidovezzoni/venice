# 8.1.3 — Sign Up

**Epic:** Cloud Sync & Multi-User
**Feature:** Backend Foundation & Auth

## User Story

As a user, I want to create an account so that my trips are stored in the cloud and accessible from any device.

## Description

A sign-up screen allows the user to register with email and password via Supabase Auth. The screen validates input (email format, password strength), shows progress during the request, and handles errors (duplicate email, network failure). On success the user is navigated to the home screen.

## Acceptance Criteria

- A sign-up screen is accessible from the login screen.
- The user enters an email address and a password (with confirmation).
- Email format and password minimum length are validated before submission.
- On successful registration, the user is authenticated and navigated to the home screen.
- Duplicate email and network errors are shown as user-friendly messages.
- A loading indicator is displayed while the sign-up request is in progress.

## Technical Notes

- **Supabase Auth:** Use `supabase.gotrue.signUpWith(Email) { email = ...; password = ... }`.
- **Email verification:** Supabase sends a confirmation email by default. Decide whether to require verification before granting access or allow immediate login.
- **MVI:** Sign-up screen follows the standard MVI pattern with `SignUpUiState`, `SignUpUiIntent`, `SignUpUiEffect`.

# 8.1.4 — Log In

**Epic:** Cloud Sync & Multi-User
**Feature:** Backend Foundation & Auth

## User Story

As a user, I want to log in to my account so that I can access my trips.

## Description

A login screen allows the user to authenticate with email and password. The session is persisted so the user does not need to log in again on subsequent app launches. Token refresh is handled transparently.

## Acceptance Criteria

- A login screen is presented when the user is not authenticated.
- The user enters email and password and taps a login button.
- On success, the user is navigated to the home screen and the session is persisted.
- Invalid credentials and network errors are shown as user-friendly messages.
- A loading indicator is displayed while the login request is in progress.
- The session survives app restarts (token persistence).

## Technical Notes

- **Supabase Auth:** Use `supabase.gotrue.signInWith(Email) { email = ...; password = ... }`.
- **Session persistence:** The Supabase Kotlin SDK can persist sessions automatically via `SettingsSessionManager` or a custom implementation backed by `EncryptedSharedPreferences`.
- **Token refresh:** The SDK handles JWT refresh automatically when configured with session persistence.

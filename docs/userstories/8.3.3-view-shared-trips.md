# 8.3.3 — View Shared Trips

**Epic:** Cloud Sync & Multi-User
**Feature:** Trip Sharing

## User Story

As a user, I want to see trips that others have shared with me so that I can view and contribute to shared roadtrip plans.

## Description

The trip list screen shows both the user's own trips and trips shared with them. Shared trips are visually distinguished (e.g. with a shared icon or the owner's name). The user can open a shared trip and interact with it according to their permission level.

## Acceptance Criteria

- The trip list includes trips shared with the current user.
- Shared trips are visually distinguished from the user's own trips (e.g. shared badge, owner name).
- Opening a shared trip shows its stops and details.
- The user can edit a shared trip if they have editor permissions.
- The user cannot delete a trip they do not own.

## Technical Notes

- **Blocked by:** Stories 8.3.1 and 8.3.2.
- **Query:** The trip list query changes from filtering by `user_id` to joining through `trip_members`, returning all trips where the user is a member.
- **UI:** Consider grouping or filtering (my trips / shared with me) or a unified list with ownership indicators.
